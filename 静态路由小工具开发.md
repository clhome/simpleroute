# 静态路由小工具开发

此工具一直在任务栏运行，主要实现静态路由的设置，开关，流量统计功能

功能要求如下：

## 1、静态路由信息输入，

支持多条，用户需要输入 目标ip，目标掩码，目标网关信息，对应的windows命令如下：

注意：这个命令必须要administer权限才能运行

```
route  add 3.3.3.3 mask 255.255.255.255 10.39.165.114
```

示例代码中 ：

3.3.3.3 为目标ip（用户配置）
	255.255.255.255为目前掩码（用户配置）

10.39.165.114 为网关 （用户配置）



## 2、每条静态路由支持开关，

关闭静态路由命令如下

注意：这个命令必须要administer权限才能运行

```
route delete 3.3.3.3
```
